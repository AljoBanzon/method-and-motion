# Method & Motion

Single-page static brochure website for Method & Motion -- Business Systems & Optimization.

## Files
- `index.html` -- website content and structure
- `styles.css` -- design and responsive layout
- `script.js` -- small reveal-on-scroll enhancement
- `assets/favicon.svg` -- browser icon
- `assets/social-preview.svg` -- basic social-sharing preview image

## Local preview
Double-click `index.html` to open it in a browser.

For a cleaner local preview, run any simple static web server from this folder.

## GitHub + Cloudflare Pages
1. Create a GitHub repository, suggested name: `method-and-motion`.
2. Upload/push all files in this folder to the repository root.
3. In Cloudflare Pages, connect the GitHub repository.
4. Framework preset: `None`.
5. Build command: leave blank.
6. Build output directory: `/` or leave as the project root when prompted for a static site.
7. Deploy.
